# Архитектура DedicatedFTPServerValheim

## Назначение

Приложение управляет жизненным циклом выделенного сервера Valheim:

1. Планирует и выполняет синхронизацию файлов между FTP и локальной временной папкой.
2. Запускает сервер через временный `.bat`.
3. Останавливает сервер и выполняет обратную синхронизацию.
4. Пишет статус запуска в `StatusServer.json`.

## Основные слои

- `DedicatedFTPServerValheim.cs` — UI (WinForms), ввод пользователя, диалоги подтверждения.
- `AppCore/AppController.cs` — orchestration: последовательность шагов Start/Stop/Upload.
- `AppCore/AppStateMachine.cs` — автомат состояний и правила блокировки действий.
- `AppCore/Sync/*` — планирование и применение синхронизации.
- `AppCore/Services/*` — сервисы статусов и процесса сервера.

## Состояния формы

- `Idle` — ожидание действий пользователя.
- `Validating` — проверка входных данных и условий запуска.
- `PlanningSync` — построение dry-run плана синхронизации.
- `ApplyingSyncDownload` — применение плана загрузки с FTP.
- `PreparingStart` — подготовка и запуск сервера.
- `Running` — сервер запущен.
- `Stopping` — остановка сервера.
- `ApplyingSyncUpload` — применение плана выгрузки на FTP.
- `Error` — ошибка выполнения.

## Модель синхронизации

Синхронизация выполняется в 2 фазы:

1. `BuildPlan(...)` — dry-run, строится список операций:
   - `Create`
   - `Update`
   - `Delete`
2. `ApplyPlan(...)` — выполнение подтвержденного плана.

Удаления не выполняются скрыто: только через операции `Delete`, попавшие в план.

## Тесты

Проект `DedicatedFTPServerValheim.Tests` покрывает:

- корректность переходов состояний;
- расчет плана синхронизации;
- базовый парсинг и генерацию `.bat`;
- чтение параметров `SettingModel`.
